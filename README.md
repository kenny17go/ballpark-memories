# Ballpark Memories

Local-first CPBL game memory PWA.

## V0.1 goal
Date → CPBL game → local photos/videos → Game Story → portable backup.

### Privacy
Original photos and videos are never uploaded. V1 has no account and no Supabase dependency.

### Architecture
- Static PWA / GitHub Pages
- Local-first storage
- CPBL source isolated behind a data adapter
- Portable backup planned before V1

Version: 0.1.0
